# Code of Conduct

CurbCharge adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
It applies to everyone participating in this repository, including issues,
pull requests, reviews, and project discussions.

Be respectful, constructive, and considerate of different perspectives.
Harassment, discrimination, threats, doxxing, and sustained disruptive
behavior are not acceptable.

For behavior on GitHub, use its **Report content** action on the relevant
issue, pull request, or comment. Avoid posting personal or sensitive details
publicly. Maintainers may edit or remove content, close contributions, or
restrict participation to enforce this policy. For security vulnerabilities,
follow the private process in [SECURITY.md](SECURITY.md).
