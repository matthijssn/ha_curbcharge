# Security policy

## Report a vulnerability privately

Use [GitHub's private vulnerability reporting page](https://github.com/matthijssn/ha_curbcharge/security/advisories/new).
Private vulnerability reporting is enabled for this repository. Do not report
vulnerabilities in public issues, discussions, or pull requests.

Include the affected CurbCharge and Home Assistant versions, the impact, and
concise reproduction steps. Use sanitized examples only. Do not include API
tokens, credentials, exact home coordinates, personal information, or
unredacted provider responses. Do not test against systems you do not own or
have permission to assess.

Please allow maintainers time to investigate and coordinate a fix before
publicly disclosing a vulnerability. No response timeline is guaranteed.
