# CurbCharge

CurbCharge brings nearby public EV charging points into Home Assistant, with
provider-reported availability, connector and tariff details, and a
best-nearby recommendation.

## Get started

Install **CurbCharge** from **HACS → Integrations**, restart Home Assistant,
then add it from **Settings → Devices & services → Add integration**. See the
[README](https://github.com/matthijssn/ha_curbcharge#readme) for installation
options and requirements.
